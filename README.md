Install the Gmsh package to run the file 'Construction of generators.ipynb' in Jupyter Notebook. 
Change the input parameters in the first cell in order to choose a mesh and set specific prefernces for how to run the algorithm.
Run all cells to perform the algorithm described in _. During that process the most important steps of the algorithm will be visualized. 
The final visualization will show the constructed generators bounding w.r.t. the exterior.
