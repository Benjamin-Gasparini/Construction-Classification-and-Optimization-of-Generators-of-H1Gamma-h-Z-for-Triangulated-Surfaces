Install the Gmsh package and papermill package to run the file 'Construction of generators_driver script.ipynb' in Jupyter Notebook (alternatively manually run all cells in 'Construction of generators.ipynb'). 
Change the input parameters in order to choose a mesh and set specific preferences for how to run the algorithm.
Running 'Construction of generators_driver script.ipynb' performs the algorithm described in 'SemesterThesis_BenjaminGasparini.pdf'. During that process the main steps of the algorithm will be visualized. 
The final visualization will show the constructed generators bounding w.r.t. the exterior.
